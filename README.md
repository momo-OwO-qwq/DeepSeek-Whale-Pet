# DeepSeek 余额小鲸鱼桌宠（Linux 独立版）

![DeepSeek 余额小鲸鱼](assets/DSH2.png)

参考 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)（DSH Web 界面右上角余额挂件）设计实现的 **Linux 桌面独立桌宠**：一只可以拖来拖去、按一下会叫、会说随机台词的小鲸鱼，随时提醒你的 DeepSeek 余额与今日消耗。**完全脱离 DSH / 浏览器运行**，只用一行命令启动。原 DSH 插件源码已从本项目清理（如需要，请到上游参考仓库查看）。

## 特性

- 🐋 **透明置顶桌宠**：鲸鱼 PNG 素材 + 自绘 SVG 气泡，无边框、无任务栏条目的浮动窗口，始终置顶
- 💰 **余额监控**：60 秒自动刷新 + 点击鲸鱼手动刷新；余额变化时数字**滚动动画**；瞬时网络抖动自动沿用最近余额不报错
- 📊 **今日已用双模式**（菜单可切换）：
  - **小鲸鱼记账（默认，免令牌）**：每次观测余额后用**余额差值**自动记账，跨天归零归档（保留 30 天）
  - **实时·令牌**：调用 DeepSeek 平台用量接口，按**峰谷定价**实时换算今日已用
- ⏰ **峰谷定价**：高峰 9:00–12:00 与 14:00–18:00（北京时间）；单价：缓存命中 0.05/0.10 元、未命中 1.5/3.0 元、输出 4.5/9.0 元（每百万 token，v4-pro 3 倍价），定价表见 `lib/balance.js`
- 🖱️ **拖拽自由定位**：**无贴边吸附**，按住即走、松手即停；**方向感知锚点**——窗口在屏幕左半时鲸鱼自动贴左（镜像）、右半贴右，因此**可触及左右边缘**；下边缘可越过任务栏贴到屏幕底；上边缘受 GNOME 合成器钳制（贴到顶部栏下）
- 🐋 **透明点击穿透**：窗口用 `setShape` 裁剪为鲸鱼/气泡/按钮区域——**点击鲸鱼的透明部分直接落到下方桌面/窗口**，不挡桌面
- 🗔 **启动即按配置缩放**：窗口在创建时即应用配置大小，改过的尺寸/位置重启后立即生效
- 🧸 **按压 Q 弹**：按压时鲸鱼压扁变形（底部坐标不变），松手过冲回弹 + **按压/松手音效**（音效1 / 音效2 两套，默认音效1，支持各自上传自定义音源）
- 💬 **随机台词气泡**：点击鲸鱼弹出余额+今日已用；点击气泡切换加权随机台词（峰谷提示/卖萌吐槽/动图），再点关闭，5 秒自动收起
- 📝 **随机台词/动图池全部文件化**：`~/.config/whale-pet/lines.json` 包含**全部默认台词与权重**（首次自动生成），可自由增删改（格式见下）
- ✏️ **自定义文案与颜色**：余额充足 / 预警两种状态分别设置气泡第一行文字（**限 20 字符**）与**颜色**；峰谷「空闲/高峰」时段文案也可自定义
- 🎵 **自定义音效**：按压/松手音效可分别上传本地音频（mp3/wav/ogg…），优先级高于音效集
- 🖼️ **主图替换**：设置里上传本地图片（png/jpg/gif/webp）作为默认显示图，复制到配置目录、随系统保留
- ⚠️ **预警换图**（默认关闭）：余额低于阈值时自动切换**独立预警图**（`assets/DSniang03.png` 存在时作默认；无此素材则默认无预警图，需上传），并显示红色 `!` 徽标
- 🌗 **暗色主题**：设置面板支持 跟随系统 / 浅色 / 深色，实时生效（含系统标题栏与原生控件；选择栏字体问题已修复）
- 🗔 **原生设置窗口 + Tab 标签页**：系统标题栏的独立设置窗，账户/数据/外观/文案/音效/图片 六个标签页分区管理；各配置文件路径均可「点击直接打开」
- ⚙️ **汉堡菜单**（悬停鲸鱼右上角出现 / 右键鲸鱼）：全部设置项一站式调整
- 🧰 **系统集成**：托盘图标（显示/隐藏/刷新/设置/自启/退出）、全局热键 `Ctrl+Shift+R` 刷新、**开机自启**（XDG autostart）、**单实例**
- 🔐 配置安全：API Key 保存于 `~/.config/whale-pet/config.json`（目录 0700 / 文件 0600）；支持环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_PLATFORM_TOKEN` 覆盖

## 快速开始

```bash
cd DeepSeek-Balance-Whale-Widget-Linux
npm install
npm start
```

启动后小鲸鱼默认出现在**屏幕右下角**。首次使用：右键鲸鱼 → 设置 → 填入 **API Key**（`sk-` 开头），即可显示余额；「今日已用」默认走免令牌的记账模式。

## 使用说明

| 操作 | 效果 |
|---|---|
| 单击鲸鱼 | 弹出气泡（余额 + 今日已用）并刷新 |
| 按住拖动 | 移动鲸鱼；松手停在该位置（无吸附），可贴到桌面任意边缘 |
| 点击气泡 | 切换随机台词段；再点一次关闭（5 秒自动收起） |
| 右键鲸鱼 / 点击右上角汉堡按钮 | 打开设置窗口 |
| `Ctrl+Shift+R` | 全局刷新余额 |

### 设置项

| 设置 | 说明 |
|---|---|
| **API Key** | 拉取余额必需；留空则鲸鱼提示「未配置」。环境变量 `DEEPSEEK_API_KEY` 优先 |
| **平台令牌** | 「实时·令牌」模式使用（DeepSeek 平台网页会话令牌，可选）；不填自动回落记账模式 |
| **用量模式** | `小鲸鱼记账`（默认，免令牌）/ `实时·令牌` |
| **大小** | 0.6–2.5 倍（默认 1.0，鲸鱼约 190px）；缩放时固定鲸鱼所在角 |
| **音效 / 音量** | 音效1 / 音效2；音量默认 100%，调 0 即静音 |
| **峰谷文案** | 内置三种风格（默认 / 梁文峰谷 / !?强强?!），另可自定义「空闲/高峰」两个词（各限 12 字符，留空=内置） |
| **气泡开关** | 关闭后点击鲸鱼不再弹气泡（余额照常刷新） |
| **闲置半透明** | 鼠标离开 3 秒后鲸鱼渐隐（可拖动闲置不透明度 20%–100%，默认 60%） |
| **刷新间隔** | 自动刷新秒数（5–3600，默认 60） |
| **低余额阈值** | 余额低于该值时弹系统通知（30 分钟去重），默认 5 元 |
| **文案·充足 / 预警** | 两种状态下气泡第一行文字（各限 20 字符）+ 各自**文字颜色**（默认色可一键恢复） |
| **预警换图** | 开启后余额低于阈值时自动把鲸鱼切换为预警图片，恢复后换回 |
| **主图 / 预警图** | 「上传」本地图片（自动复制到 `~/.config/whale-pet/images/`，与源文件解耦）；「默认」回到内置素材（预警图默认 `assets/DSniang03.png`，无此素材则默认无预警图）。主图与预警图彼此独立 |
| **随机台词**（文案页） | 「重新载入」读取 `lines.json`（启动时自动生成默认值）；「打开文件」直接用系统编辑器打开 |
| **按压 / 松手音效** | 分别上传自定义音源（复制到 `~/.config/whale-pet/sounds/`，优先级高于音效集） |
| **主题** | 设置面板深色模式：跟随系统 / 浅色 / 深色 |
| **开机自启** | 写入 `~/.config/autostart/deepseek-balance-whale-pet.desktop` |

## 自定义随机台词与动图（lines.json）

`~/.config/whale-pet/lines.json`（**首次运行自动生成，含全部默认台词与权重**），修改后在 设置 → 图片台词 → **重载**：

```json
{
  "gif": "",
  "groups": [
    { "weight": 45, "type": "balance" },
    { "weight": 7, "lines": [{ "text": "好模型... ↓", "style": "B" }, { "text": "好女孩...↓", "style": "B" }] },
    { "weight": 10, "type": "gif" },
    { "weight": 3, "lines": [{ "text": "自定义台词", "style": "A", "wrap": true, "color": "#ff8800" }] }
  ]
}
```

- `groups`：随机组，按 `weight` 加权抽取（最多 12 组）；`type: "balance"` = 动态组（峰谷时段+今日已用）、`type: "gif"` = 动图组；`lines` 组最多 3 行（不足补空、超出截断）
- 条目字段：`text` 限 40 字符；`style` 取值 `A`（标签）/`B`（大字金额位）/`P`（峰谷大字）/`C`（提示行）；`wrap` 是否自动换行；`color` 可选（`#rrggbb`）
- `gif`：自定义动图路径（绝对路径或 http(s)），可留空；存在时替换内置 `rua.gif`

## 配置与数据

所有数据保存在 `~/.config/whale-pet/`：


## 常见问题

- **窗口黑底/不透明**：透明窗口需要桌面合成器（GNOME/KDE/XFCE 默认开启）。若在无合成器的环境运行，可关闭桌面特效或改用普通窗口模式。
- **Wayland 下拖拽不动**：应用已默认强制走 XWayland（`ozone-platform=x11`）以保证窗口定位；如需改回，设置 `ELECTRON_OZONE_PLATFORM_HINT=auto`。
- **托盘图标不显示**：GNOME 需要 AppIndicator 扩展（KDE/XFCE 内置）；没有托盘不影响使用，右键鲸鱼可打开设置。
- **没有声音**：`assets/*.mp3` 必须存在；音量调 0 即静音；某些精简发行版需安装系统音频组件。
- **今日已用显示 --**：记账模式需先完成一次余额观测（点击鲸鱼或等自动刷新）；令牌模式需配置平台令牌。
- **余额不更新**：检查网络与 API Key 有效性；瞬时失败（超时/5xx）时鲸鱼会沿用最近余额不报错。
- **配置放哪**：`~/.config/whale-pet/config.json`；可用环境变量 `WHALE_PET_HOME` 重定向（脚本化/测试用）。

## 与原版差异对照

| 项目 | 原版（DSH Web 插件） | 本 Linux 桌宠版 |
|---|---|---|
| 运行环境 | DSH Web 界面（注入页面） | 独立 Electron 桌面应用 |
| 启动方式 | DSH 页面加载自动注入 | 用户启动 / 开机自启 |
| 定位 | 右下角固定（避让滚动条） | 自由拖拽（无吸附）+ 位置记忆 |
| 动效 | 按压 Q 弹 | 按压 Q 弹 + **呼吸 + 闲置半透明 + 情绪表情 + 预警换图** |
| 系统集成 | 无 | 托盘 + 全局热键 + 系统通知 + 单实例 |
| 点击命中 | 页面内透明区穿透 | **setShape 窗口裁剪**：鲸鱼/气泡/按钮之外点击落到桌面 |
| 配置存储 | `$DSH_HOME/.dshw-size.json` | `~/.config/whale-pet/config.json` |
| 记账存储 | `$DSH_HOME/.dshw-usage.json` | `~/.config/whale-pet/usage.json` |
| API Key | DSH 凭据服务 | 设置窗口手动填写（或环境变量） |
| 每轮消耗统计 | 监听 DSH 会话事件 | 不适用（独立应用），其余功能 1:1 移植 |
